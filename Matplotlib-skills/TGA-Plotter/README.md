# TGA Plotter — 熱重分析數據繪圖工具

> 熱重分析（TGA）數據繪圖 GUI：解析 NETZSCH 匯出格式、多檔案疊加、
> Weight% / 失重% / DTG 多模式。開源（MIT）· academic-toolkit 一部分。

## ✨ 功能

| 功能 | 說明 |
|------|------|
| **NETZSCH 格式解析** | 自動跳過 `#` metadata、讀取初始重量（Weight: 7.2 mg）|
| **通用 CSV** | 一般 T/weight 兩欄 CSV，手動選欄位 |
| **多檔案疊加** | 列表管理，多樣品/條件畫在同一圖比較 |
| **Y 軸 4 模式** | A=Δm(mg)原始 / B=Weight% / C=失重% / DTG 導數 |
| **X 軸切換** | 溫度 (°C) / 時間（有時間欄時）|
| **初始重量覆寫** | 自動讀 metadata，屬性視窗可手動改 |
| **完整 GUI** | 列表/↑↓排序/屬性/圖例互動/軸設定/標註/儲存 |

## Y 軸模式公式

| 模式 | 公式 |
|:--:|:--:|
| **A** Δm (mg) | 原始質量變化 |
| **B** Weight (%) | (W0 + Δm)/W0 × 100（剩餘重量，從 ~100% 下降）|
| **C** 失重 (%) | −Δm/W0 × 100 = 100 − B |
| **DTG** | d(Weight%)/dX（%/°C 或 %/min，X=溫度或時間）|

W0 = 初始重量（mg），Δm = 原始質量變化（負=失重）

## 📦 安裝

```bash
pip install matplotlib pandas numpy
```

## 🚀 使用

```bash
python tga_plotter.py
```

### 載入
1. 「＋ 新增」→ 選 .txt/.csv → 彈窗自動偵測 X 軸/重量欄 + 初始重量（自動讀取）
2. 列表顯示「名稱 (初始重量)」

### Y 軸模式
全域設定「Y 軸」下拉：A / B / C / DTG

### X 軸
全域設定「X 軸」下拉：Temperature / Time（有時間欄時）

### 初始重量覆寫
列表選取 →「✎ 屬性」→ 改「初始重量 (mg)」→ 套用
